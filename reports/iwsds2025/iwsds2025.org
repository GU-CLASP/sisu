#+TITLE: SISU: Statecharts meet Information State Update approach

* Abstract

Large language models (LLMs) remain undeniably uncontrolled, but their
capabilities have raised the bar for conversational AI. This makes an
argument for using Information State Update (ISU) for mitigating the
risks associated with using LLMs, for instance, through pre-generating
dialogue domains (Larsson, 2024) and generating natural language
responses. In the proposed framework, SISU, we use the statecharts
formalism (Harel, 1987) in combination with modern features of a
TypeScript progamming language thus allowing running dialogue
applications both in frontend (in-browser voice-enabled dialogue) and
backend (controlling social robots, running automated tests). SISU
implements a version of IBiS1 (Larsson, 2002), but it improves over it
by providing a capacity for coding parts of a dialogue domain using
statecharts, for instance, for domains and aspects that only have a
procedural description.


Large language models (LLMs) remain undeniably uncontrolled, but their
capabilities have raised the bar for conversational AI. This makes a
compelling argument for using Information State Update (ISU) to
mitigate the risks associated with using LLMs. In controlled ISU-based
systems, LLMs offer benefits such as pre-generating dialogue domains
(Larsson, 2024) and generating natural language responses.

In our proposed framework, SISU, we combine the statecharts formalism
(Harel, 1987) with modern features of the TypeScript programming
language. This allows us to run dialogue applications in both frontend
(in-browser voice-enabled dialogue) and backend (controlling social
robots, running automated tests) environments.

SISU implements a version of IBiS1 (Larsson, 2002), but improves upon
it by providing the capacity to code parts of a dialogue domain using
statecharts. This is particularly useful for domains and aspects that
have only a procedural description.

- Staffan Larsson (2024) Pre-Generative Conversational AI, SEMDIAL.
- David Harel (1987) Statecharts: a visual formalism for complex systems, Science of Computer Programming.
- Staffan Larsson (2002) Issue-based dialogue management, Department of Linguistics, Göteborg University.
